# AdminPanel

Красивая админ-панель для Paper 26.2

## Возможности

- **`/apanel`** — открывает главное меню админ-панели
  - **Игроки** — список всех онлайн-игроков (головы)
    - Клик по голове → меню действий:
      - **Забанить** — перманентный бан
      - **Кикнуть** — кик с сервера
      - **Мут / Размут** — переключение мута в чате
      - **Слежка** — невидимость + полёт + телепорт к игроку
  - **Репорты** — список активных жалоб
    - **ЛКМ** — телепорт к игроку, на которого пожаловались
    - **ПКМ** — закрыть репорт

- **`/report <ник> <причина>`** — отправить жалобу на игрока  
  Админы получают уведомление в чат.

## Права

| Право | Описание | По умолчанию |
|-------|----------|--------------|
| `adminpanel.use` | Открывать панель | op |
| `adminpanel.report` | Писать репорты | true |
| `adminpanel.ban` | Банить | op |
| `adminpanel.kick` | Кикать | op |
| `adminpanel.mute` | Мутить | op |
| `adminpanel.spectate` | Слежка | op |
| `adminpanel.reports` | Смотреть репорты | op |

## Сборка

Плагин автоматически собирается GitHub Actions при каждом пуше в `main`.

Готовый `.jar` можно скачать во вкладке **Actions** → последний workflow → Artifacts.

### Локальная сборка

```bash
./gradlew build
```

Готовый файл: `build/libs/AdminPanel-1.0.0.jar`
